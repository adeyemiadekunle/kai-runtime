The first Kai runtime release: fx 0.0.17 with the Kai runtime's changes, published privately to GitHub Packages for Dotrix's Chat (Nova) and Codes (Kai).

## What's new since fx 0.0.17

- **Security:** `project_config` (profile-only) and `FX_PROJECT_CONFIG` let a host stop fx taking configuration from the repository it works in: `.fx.json`, `.fx/agents`, skill folders, `.mcp.json` and project instructions such as `AGENTS.md`. A repository can't turn it back on.
- **`max_subagents`** caps how many subagents work at once (profile-only; `too_many_subagents` when full).
- **Fix:** an answer cut off at the provider's output limit is no longer replayed as complete. A retried turn reports `max_output_tokens`, and journals and checkpoints that hold one are version 5, which fx 0.0.16 and 0.0.17 refuse rather than misread.
- **Packaging:** private publishing to GitHub Packages; fx's own publishing workflows run only upstream.

The full list is in [CHANGELOG.md](https://github.com/adeyemiadekunle/kai-runtime/blob/main/CHANGELOG.md).
