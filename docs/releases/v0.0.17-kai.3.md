The third Kai runtime release, published privately to GitHub Packages for Dotrix's Codes (Kai).

## What's new since 0.0.17-kai.2

- **Kept shell commands over ACP:** a `shell` call's final `tool_call_update` names a command fx keeps in `_meta.fx.shell`: `{sessionId, state[, exitCode]}`. On `session/load`, replayed updates carry the same metadata from the saved result, marked `historical: true`.
- **`fx/shells`:** a new ACP request that lists the commands an fx process keeps: `{shells: [{sessionId, command, state, exitCode?, signal?, output, startedMs}]}`.
  - `output` is the last 4 KiB a command printed.
  - Finished commands fx still keeps are listed too.
  - It is answered during a prompt as well.
  - Kept commands live as long as the process, across prompts.
- **Fix: a kept command crashed fx.** A command left running after its prompt crashed fx with SIGSEGV when it printed, because its live output still went to the ended prompt's context. A prompt now detaches from its commands before returning.

The full list is in [CHANGELOG.md](https://github.com/adeyemiadekunle/kai-runtime/blob/main/CHANGELOG.md).
