The second Kai runtime release, published privately to GitHub Packages for Dotrix's Chat (Nova) and Codes (Kai).

## What's new since 0.0.17-kai.1

- **Agent profiles over ACP:** the `subagent` tool lists the profiles a subagent can start in, the host's `~/.fx/agents` and the repository's when `project_config` allows, whenever one exists besides the built-in `main` and `agent`. Before, an ACP host's profiles could be started by name, but the model was never told they existed.
- **Limits per agent:** an agent profile's `max_steps` lowers its parent's step limit. Its `max_tokens` counts every model request's input and output as the provider reports them. An agent past either stops before its next model call, and its parent hears why.
- **Gemini's tool calls:** a Chat Completions stream whose tool-call deltas carry no `index` is placed by id, or continues the last call. A `stop` that ends such a stream is read as `tool_calls`.
- **libfx correlation ID:** `prompt()` and `resume()` take a `correlationId`. The turn, every one of its events, and its result carry it.
- **Packaging:** the private publishing workflow runs on GitHub. It installs Bun for the package checks and publishes with `--tag latest`, which npm 11 requires for a prerelease version.

The full list is in [CHANGELOG.md](https://github.com/adeyemiadekunle/kai-runtime/blob/main/CHANGELOG.md).
