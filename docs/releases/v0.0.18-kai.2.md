The second Kai runtime release on fx 0.0.18, published privately to GitHub Packages for Dotrix's Chat (Nova) and Codes (Kai).

## What's new since 0.0.18-kai.1

- **`fx --version` reports the Kai release:** `fx --version`, `fx -v`, and ACP `initialize`'s `agentInfo.version` report `0.0.18-kai.2`. Before this release, every Kai build on fx 0.0.18 reported `0.0.18`, so a host could tell Kai from upstream fx only by `fx config get project_config`, and could not tell one Kai release from another.
- **How it's built:** `zig build -Dkai-release=<fx version>-kai.<n>` sets the release. `publish-private-libfx.yml` passes the version it publishes, and `package-private-cli.sh` refuses a binary that reports another.
- **What still uses the fx version:** a build without the option reports `0.0.18`. Update checks, saved sessions, `fx --help`, and libfx keep using the fx version. The runtime is otherwise unchanged from 0.0.18-kai.1.

The full list is in [CHANGELOG.md](https://github.com/adeyemiadekunle/kai-runtime/blob/main/CHANGELOG.md).
